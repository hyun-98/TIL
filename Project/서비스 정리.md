# DBMS

| 항목     | MongoDB   | MySQL / PostgreSQL |
| ------ | --------- | ------------------ |
| 구조     | 자유 (JSON) | 고정 (테이블)           |
| 유연성    | 매우 높음     | 낮음                 |
| 속도(개발) | 빠름        | 느림                 |
| 안정성    | 상대적으로 낮음  | 높음                 |
| 관계 데이터 | 약함        | 매우 강함              |
| 대표 사용  | 스타트업, MVP | 금융, 대기업            |
