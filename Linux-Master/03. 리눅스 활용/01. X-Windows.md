# 🖥️ # 01. 개념 및 사용법

---

## 📌 A. X-윈도우의 특징과 구성 요소

### 🔹 1) X-윈도우

👉 linux/UNIX에서 GUI(그래픽 화면)을 보여주는 시스템

---

### 🔹 2) X-윈도우 구성요소

* 🧩 XProtocol
* 📚 Xlib
* ⚡ XCB
* 🛠️ Xtoolkit
* 🖥️ XFree86
* ⚙️ XF86Config

---

## 📌 B. X-윈도우 설정과 실행

### 🔹 1) X-윈도우 실행

👉 리눅스에서 GUI 환경을 실제로 "켜는 것"

```
startx -- [인자값]
```

---

### 🔹 2) 환경 변수 DISPLAY

👉 X-윈도우에서 "어디 화면에 출력할지" 알려주는 값

```
export DISPLAY=IP주소: 디스플레이번호 . 스크린번호
```

---

## 📌 C. 윈도우 매니저와 데스크톱 환경

### 🔹 1) 윈도우 매니저

👉 창의 위치, 크기, 테두리, 움직임을 관리하는 프로그램

* 🪟 fvwm
* 🪟 twm
* 🪟 AfterStep
* 🪟 Window Maker
* 🪟 Blackbox
* 🪟 kwm
* 🪟 Enlightment

---

### 🔹 2) 데스크톱 환경

👉 리눅스를 윈도우처럼 사용할 수 있게 해주는 완성형 UI 패키지

📦 구성

* 윈도우 매니저
* 파일 탐색기
* 패널(시작메뉴/작업표시줄)

* 기본 앱

⭐ 대표

* 🖥️ KDE
* 🖥️ GNOME
* 🖥️ LXDE
* 🖥️ XFCE

---

### 🔹 3) 디스플레이 매니저

👉 부팅 후 로그인 화면을 보여주고, 데스크톱 환경을 실행해주는 관리자

* 🔐 xdm
* 🔐 dtlogin
* 🔐 kdm
* 🔐 gdm

# 🌐 # 02. X-윈도우 활용

---

## 📌 A. 원격지에서 X 클라이언트 이용

👉 다른 컴퓨터(서버)에서 프로그램 실행 -> 내 화면에 GUI로 띄우는 것
👉 (서버가 화면을 보여주는 개념이 아니라, 내 PC가 화면을 그린다)

---

### 🔹 1) xhost

👉 누가 내 X서버에 접근할 수 있는지 허용하는 명령어

---

### 🔹 2) xauth

👉 인증 토큰(쿠키) 기반으로 X 서버 접근을 제어

---

## 📌 B. X-윈도우 응용 프로그램

👉 X-윈도우 환경에서 실행되는 GUI 프로그램
👉 X 서버에 화면을 그려달라고 요청하는 프로그램(X client)

📌 구조

* X 서버 : 🖥️ 화면 담당
* 프로그램 : ⚙️ X client
