# 02. 리눅스의 역사

1969 켄 톰슨, 데니스 리치 - UNIX
1983 리처드 스톨만 - GNU 프로젝트
1985 리처드 스톨만 - FSF 설립
1991 리누스 토르발즈 - GNU/Linux 개발


# 03. 리눅스 라이선스

GNU GPL : Free 소프트웨어 라이선스

GNU LGPL : 완화된 조건의 공개 소프트웨어 라이선스

BSD 라이선스 : 버클리(B) 캘리포니아 / 소스코드 공개 의무 X, 상용 소프트웨어 무제한 사용 가능

Apache 라이선스 : 아차피 재단에서 자체적으로 만든 소프트웨어 라이선스 규정

MIT 라이선스 : BSD를 기초로 작성

MPL : 모질라 재단, MPL은 특징은 소스코드와 실행파일의 저작권을 분리
