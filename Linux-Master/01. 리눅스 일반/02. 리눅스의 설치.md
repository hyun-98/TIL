# 03. 부트 매니저 (Boot Manager)

## A. 부팅 과정의 이해

BIOS -> MBR /-> BOOT Loader -> Kernel -> Systemd -< Login shell

PC Booting /-> Linux Booting


HDD 0번 sector : MBR(master boot record) 로딩 -> Boot Code, Partition table

## B. 리눅스 부팅 단계별 동작

부트로더(LILO, GRUB)

## C. 로그인과 사용자 세션 관리
