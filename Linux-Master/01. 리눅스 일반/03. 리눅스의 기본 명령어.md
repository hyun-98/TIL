# 01. 사용자 생성 및 계정 관리

## A. 명령어와 도움말의 사용법

명령어 which : 명령어의 경로를 확인

명령어 alias : 별칭

명령어 unalias : alias 기능을 해제한다

환경변수 PATH : 명령어를 찾는 '폴더 목록'

<리눅스 도움말>

man [섹션] [옵션] 명령어 : 리눅스에서 사용하는 명령어들의 메뉴얼 제공

info 명령어 : 리눅스 명령어의 사용 방법, 옵션 등을 나타낸다

whatis 명령어 : 명령어에 대한 기능을 간략하게 나타낸다

manpath 명령어 : man 페이지의 위치 경로를 검색하여 표시해 주는 명령어

whereis [옵션] 명령어 : 찾고자 하는 명령어의 실행 파일 절대 경로와 소스코드, 설정 파일 및 매뉴얼 페이지를 찾아 출력하는 명령

apropos 문자열 : man 페이지 설명에서 지정한 키워드를 포함하고 있는 명령어 - whatis 데이터베이스가 만들어져 있어야 사용 가능



## B. 사용자 생성 명령어

useradd [옵션] 계정명 : 계정을 생성하는 명령어

passwd [옵션] 계정명 : 생성된 계정자의 패스워드를 입력 및 변경하는 명령어

su [옵션] [사용자] [셸변수] : 현재의 사용자 계정에서 로그아웃하지 않고 다른 사용자 계정으로 로그인하여 해당 사용자의 권한을 획득하는 명령어

# 02. 디렉터리 및 파일

## A. 디렉터리와 파일의 관리

pwd : 현재 작업 중인 Directory의 위치를 나타내는 명령어

cd(Change Directory) : Directory를 이동할 때 사용하는 명령어

mkdir [옵션] 디렉터리명 : 새로운 디렉터리 생성

rmdir 디렉터리명 : 디렉터리 삭제 (내부에 file 존재시 삭제 x)



<File 관련 명령어>

ls [옵션] [경로명] : 현재 위치한 Directory의 file 목록들을 나타냄

cp [옵션] [원본] [대상] : file/Directory 복사

rm [옵션] [파일/디렉터리] : file/Directory 삭제

mv [옵션] [원본] [대상] : file/Directory 이동하거나 파일명을 변경할 때 사용

touch [옵션] [파일] : file 크기가 o byte인 empty file 생성 / 서버의 현재 시간으로 파일의 타임스탬프 수정

file [옵션] [파일] : 파일의 종류 속성값을 나타내는 명령어

find [경로] [옵션] [정규표현식] [파일] : 주어진 조건의 파일을 찾아 경로를 표시

locate [파일] : 파일의 위치를 찾는 명령어


## B. 파일의 처리와 입출력 제어

cat [옵션] [파일] : 파일의 내용을 출력하는 명령어
