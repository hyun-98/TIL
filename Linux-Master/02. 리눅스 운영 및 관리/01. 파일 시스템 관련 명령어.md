
# 📘 01. 권한 및 그룹 설정

## 🅰️ A. 파일 권한 및 소유권 관리

### 🔹 chown

* 소유권 변경 (소유자 + 소유 그룹)

```bash
chown user:group file
chown -R user:group directory
```

---

### 🔹 chgrp

* 그룹 소유권 변경 (소유 그룹만 변경)

```bash
chgrp group file
chgrp -R group directory
```

---

### 🔹 chmod

* 접근 권한 변경

```bash
chmod 755 file
chmod -R 755 directory
```

---

### 🔹 umask

* 새로 생성되는 파일/디렉터리 기본 권한 설정
* 파일: `666` / 디렉터리: `777`

```bash
umask
umask -S   # 문자 형태로 출력
```

---

## 🅱️ B. 디스크 자원 관리

### 🔹 quotaoff

* 쿼터 서비스 비활성화

| 옵션   | 설명     |
| ---- | ------ |
| `-a` | 모든 파티션 |
| `-u` | 사용자 쿼터 |
| `-g` | 그룹 쿼터  |
| `-v` | 메시지 출력 |

---

### 🔹 quotacheck

* 디스크 사용량 검사

| 옵션   | 설명         |
| ---- | ---------- |
| `-a` | 모든 파일 시스템  |
| `-u` | 사용자 쿼터     |
| `-g` | 그룹 쿼터      |
| `-m` | 재마운트 생략    |
| `-n` | 첫 번째 결과 사용 |
| `-p` | 결과 출력      |
| `-v` | 상태 출력      |

---

### 🔹 edquota

* 편집기로 쿼터 설정

| 옵션   | 설명            |
| ---- | ------------- |
| `-u` | 사용자           |
| `-g` | 그룹            |
| `-t` | 유예기간          |
| `-p` | 다른 사용자와 동일 설정 |

---

### 🔹 setquota

* 명령어로 직접 설정

| 옵션   | 설명       |
| ---- | -------- |
| `-u` | 사용자      |
| `-g` | 그룹       |
| `-a` | 전체 적용    |
| `-t` | 유예기간 (초) |

# 📘 02. 파일 시스템 관리

---

### 🔹 mount

* 장치 ↔ 디렉터리 연결

| 옵션   | 설명           |
| ---- | ------------ |
| `-a` | fstab 전체 마운트 |
| `-n` | mtab 기록 안 함  |
| `-f` | 테스트          |
| `-t` | 파일 시스템 지정    |
| `-o` | 추가 옵션        |

---

### 🔹 umount

* 마운트 해제

| 옵션   | 설명          |
| ---- | ----------- |
| `-a` | 전체 해제       |
| `-n` | mtab 갱신 안 함 |
| `-t` | 타입 지정       |

---

### 🔹 eject

* CD/DVD 등 장치 제거

| 옵션   | 설명        |
| ---- | --------- |
| `-r` | CD-ROM 해제 |
| `-t` | 플로피 해제    |

---

### 🔹 fdisk

* 파티션 관리

```bash
fdisk [옵션] [장치명]
```

| 옵션   | 설명     |
| ---- | ------ |
| `-v` | 버전     |
| `-l` | 파티션 정보 |
| `-s` | 크기 출력  |

---

### 🔹 mkfs

* 파일 시스템 생성

| 옵션   | 설명           |
| ---- | ------------ |
| `-V` | 상세 출력        |
| `-t` | 타입 지정        |
| `-c` | bad block 검사 |
| `-l` | badblock 목록  |
| `-v` | 상태 출력        |

---

### 🔹 mke2fs (ext 전용)

| 옵션   | 의미        | 설명         | 예시                         |
| ---- | --------- | ---------- | -------------------------- |
| `-t` | 파일 시스템 종류 | ext2/3/4   | `mke2fs -t ext4 /dev/sda1` |
| `-b` | 블록 크기     | 저장 단위      | `-b 4096`                  |
| `-i` | inode 비율  | inode당 바이트 | `-i 16384`                 |
| `-N` | inode 수   | 직접 지정      | `-N 100000`                |
| `-L` | 라벨        | 이름 지정      | `-L DATA`                  |
| `-c` | 검사        | bad block  | `-c`                       |
| `-j` | 저널링       | 복구 기능      | `-j`                       |
| `-m` | 예약 공간     | root용      | `-m 5`                     |
| `-F` | 강제        | 덮어쓰기       | `-F`                       |
| `-S` | 슈퍼블록      | 재생성        | `-S`                       |

---
