# 01 권한 및 그룹 설정

## A. 파일 권한 및 소유권 관리

chown : 소유권 변경 (소유자 + 소유 그룹)
chown -R (하위 directory 변경)

chgrp : 그룹 소유권 변경 (소유 그룹만 변경)
chgrp -R 

chmod : 접근 허가권 변경
chmod -R

umask : 새로 생성되는 파일이나 디렉터리의 기본 허가권을 지정
파일 666, 디렉토리 777
umask -S (umask 값을 문자로 표시)

## B. 디스크 자원 관리

quotaoff : 쿼터 서비스를 비활성화
-a : 파티션 정보 출력
-u : 사용자 쿼터 비활성화
-g : 그룹쿼터 비활성화
-v : 메시지 출력

quotacheck : 파일 시스템의 디스크 사용 상태를 검색
-a : 모든 파일 시스템을 체크(all)
-u : 사용자 쿼터 관련 체크(user)
-g : 그룹 쿼터 관련 체크(group)
-m : 재마운트를 생략(no-remount)
-n : 첫 번째 검색된 것을 사용
-p : 처리 결과를 출력
-v : 파일 시스템의 상태를 보여줌

edquota : 편집기를 이용하여 사용자나 그룹에 디스크 사용량을 할당
-u : 사용자 디스크 할당량 설정
-g : 그룹 디스크 할당량 설정
-t : 디스크 할당량 유예기간 설정
-p : 디스크 할당량 설정을 다른 사용자와 동일하게 설정

setquota : 편집기 x, 명령행에서 직접 디스크 사용량 할당
-u : 사용자 디스크 할당량 설정
-g : 그룹 디스크 할당량 설정
-a : 해당 시스템의 모든 설정
-t : 유예기간을 초 단위로 설정


# 02 파일 시스템의 관리

## A. 파일 시스템의 개념과 관리

mount 장치 - 디렉터리 연결
-a : /etc/fstab 파일에 정의된 모든 시스템 마운트
-n : /etc/matb 파일에 정보를 저장하지 않고 마운트
-f : 실제 마운트하는 것이 아니라 마운트가 가능한지를 테스트
-t : 파일 시스템 관련
-o : 추가 설정

umount : 마운트 해제
-a : 파일 /etc/mtab에 명시된 파일 시스템 마운트 해제
-n : 파일 /etc/mtab 파일을 갱신하지 않고 마운트 해제
-t : 언마운트 할 파일 시스템을 지정

eject : 이동식 보조기억장치(DVD, CD-ROM) 과 같은 미디어를 해제하고 장치를 제거하는 명령어
-r : CD-ROM 마운트 해제
-t : 플로피를 마운트 해제

fdisk  : 파티션 관련 작업(파티션 생성, 파티션 삭제, 파티션의 타입 결정)
fdisk [옵션] [장치명]
-v : fdisk 버전 정보 표시
-l : 현재 디스크의 파티션 테이블 정보 표시
-s : 지정된 파티션의 크기를 불록 단위로 표시

mkfs :  리눅스 파일 시스템 생성 (fdisk로 파티션을 나눈 뒤 mkfs로 해당 파티션에 맞는 파일 시스템을 제공)
-V : 자세한 정보 보기
-t [파일시스템] : 생성할 파일 시스템 타입 지정
-c : 파일 시스템을 생성하기 전에 badBlock 검사
-l [파일명] : 지정된 파일명으로부터 badblock 목록 읽기
-v : 작업 상태와 결과를 자세히 보기

mke2fs : ext2, ext3, ext4 타입의 리눅스 파일시스템 생성
mke2fs [옵션] [장치명]

| 옵션   | 의미          | 설명                    | 예시                           |
| ---- | ----------- | --------------------- | ---------------------------- |
| `-t` | 파일 시스템 종류   | ext2 / ext3 / ext4 지정 | `mke2fs -t ext4 /dev/sda1`   |
| `-b` | 블록 크기       | 파일 저장 단위 크기 설정        | `mke2fs -b 4096 /dev/sda1`   |
| `-i` | inode 크기 비율 | inode 1개당 바이트 수       | `mke2fs -i 16384 /dev/sda1`  |
| `-N` | inode 개수    | 생성할 inode 수 직접 지정     | `mke2fs -N 100000 /dev/sda1` |
| `-L` | 라벨 이름       | 파일 시스템 이름 지정          | `mke2fs -L DATA /dev/sda1`   |
| `-c` | 불량 블록 검사    | bad block 체크 후 생성     | `mke2fs -c /dev/sda1`        |
| `-j` | 저널링 추가      | ext3/4에서 복구 기능 추가     | `mke2fs -j /dev/sda1`        |
| `-m` | 예약 공간 비율    | root용 공간 (%) 확보       | `mke2fs -m 5 /dev/sda1`      |
| `-F` | 강제 실행       | 기존 데이터 무시하고 생성        | `mke2fs -F /dev/sda1`        |
| `-S` | 슈퍼블록 재생성    | superblock만 다시 생성     | `mke2fs -S /dev/sda1`        |

fsck : 파일 시스템의 무결성을 점검하고 복구

| 옵션   | 의미           | 설명                            | 예시                  |
| ---- | ------------ | ----------------------------- | ------------------- |
| `-A` | 전체 검사        | `/etc/fstab`에 있는 모든 파일 시스템 검사 | `fsck -A`           |
| `-t` | 파일 시스템 종류    | 특정 파일 시스템만 검사                 | `fsck -t ext4`      |
| `-a` | 자동 복구        | 문제를 자동으로 수정 (yes 자동 선택)       | `fsck -a /dev/sda1` |
| `-y` | 강제 자동 복구     | 모든 질문에 yes로 답변                | `fsck -y /dev/sda1` |
| `-n` | 읽기 전용 검사     | 수정 없이 검사만 수행                  | `fsck -n /dev/sda1` |
| `-r` | 수동 복구        | 사용자에게 물어보면서 복구                | `fsck -r /dev/sda1` |
| `-f` | 강제 검사        | 정상으로 보여도 강제로 검사               | `fsck -f /dev/sda1` |
| `-c` | bad block 검사 | 불량 블록 검사 포함                   | `fsck -c /dev/sda1` |
| `-V` | 자세히 출력       | 진행 과정 상세 출력                   | `fsck -V /dev/sda1` |


e2fsck : ext2,ext3,ext4 타입의 리눅스 파일 시스템을 점검, 복구하는 명령어 (ext2/3/4 전용 fsck)

| 옵션   | 의미           | 설명                | 예시                          |
| ---- | ------------ | ----------------- | --------------------------- |
| `-a` | 자동 복구        | 오류를 자동으로 수정       | `e2fsck -a /dev/sda1`       |
| `-y` | 강제 자동 복구     | 모든 질문에 yes        | `e2fsck -y /dev/sda1`       |
| `-n` | 읽기 전용 검사     | 수정 없이 검사만 수행      | `e2fsck -n /dev/sda1`       |
| `-f` | 강제 검사        | 정상이어도 검사 수행       | `e2fsck -f /dev/sda1`       |
| `-c` | bad block 검사 | 불량 블록 검사          | `e2fsck -c /dev/sda1`       |
| `-p` | 자동 복구 (안전)   | 위험하지 않은 문제만 자동 수정 | `e2fsck -p /dev/sda1`       |
| `-v` | 자세히 출력       | 진행 과정 상세 표시       | `e2fsck -v /dev/sda1`       |


du : 디스크 사용량을 확인
