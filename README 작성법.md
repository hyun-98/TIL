#  Github 관리

1. repo 이름!

2. 커밋 메시지 (Prefix)
ex. 
feat: 로그인 API 추가				// 새 기능 추가
fix: 회원가입 validation 오류 수정		// 버그 수정
docs: README 업데이트			// 문서 수정
refactor: user service 구조 개선		// 기능 변화 없이 코드 구조 개선
test: user service unit test 추가		// 테스트 코드
style: prettier 적용				// 코드 포맷팅

3. .gitignore 관리 (불필요한 file 올리지 않기)
