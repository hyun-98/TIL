# 설치하면 유용한 extensions

## 1. 기본 생산성

- prettier : 코드 자동 정렬
- ESLint : 코드 오류 + 스타일 체크
- Material Icon Theme : 파일 아이콘 보기 좋게 변경
- Error Lens : 에러를 코드 옆에 바로 표시

## 2. Python 개발용

- python
- pylance : 자동완성 + 타입분석
- Ruff : 빠른 lint + formatter

## 3. Java

- Extension Pack for Java

## 4. React

- ES7 + React Snippets : 컴포넌트 자동 생성
- Auto Rename Tag : 태그 자동 변경

## 5. Tailwind CSS

- Tailwind CSS IntelliSense : 클래스 자동완성 / 색상 미리보기
- RapidTail : React + Tailwind 스니펫 강화

## AI
- Github Copilot
- Codeium(무료) 자동 코드 생성 + 설명
