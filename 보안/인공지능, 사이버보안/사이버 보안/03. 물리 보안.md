# 📘 Physical & Authentication Security 정리

---

# 1. 🏢 물리 보안 (Physical Security)

👉 건물, 장비, 시설 등 물리적인 자산을 보호하는 보안

## 🔍 목적
- 외부 침입 방지
- 내부 자산 보호
- 정보 시스템 물리적 손상 방지

## 🧱 예시
- 출입 통제 시스템 (카드키, 지문)
- CCTV
- 보안 게이트
- 경비 인력
- 서버실 잠금장치

---

# 2. 🧬 생체 인증 (Biometric Authentication)

👉 사람의 생체 정보를 이용해 본인 여부를 인증하는 방식

## 🔍 종류

### 👁️ 생체 신호 인증
- 지문 인식
- 얼굴 인식
- 홍채 인식
- 정맥 인식
- 음성 인식

## 🔥 특징
- 비밀번호보다 안전
- 분실 위험 없음
- 복제가 어렵지만 100% 안전은 아님

---

# 3. 📹 지능형 영상 보안 (Intelligent Video Security)

👉 AI를 활용해 CCTV 영상을 분석하는 보안 기술

## 🔍 기능
- 침입자 자동 감지
- 이상 행동 탐지
- 얼굴 인식
- 객체 추적
- 군중 밀집 분석

## 🧠 특징
- 사람이 직접 모니터링하지 않아도 됨
- AI 기반 실시간 분석
- 보안 사고 자동 알림

---

# 4. 🛂 전자 여권 (e-Passport)

👉 전자칩이 내장된 디지털 여권

## 🔍 구성
- 여권 정보 (이름, 국적, 번호)
- 생체 정보 (얼굴 이미지 등)
- 디지털 서명

## 🔥 보안 기술
- 암호화된 RFID 칩
- 디지털 서명으로 위변조 방지
- ICAO 국제 표준 사용

## 🧠 특징
- 위조 어려움
- 출입국 자동화 가능
- 보안성과 편의성 증가

---

# 📊 요약

| 기술 | 핵심 |
|------|------|
| 물리 보안 | 실제 공간/장비 보호 |
| 생체 인증 | 신체 정보로 인증 |
| 지능형 영상 보안 | AI 기반 CCTV 분석 |
| 전자 여권 | 디지털 + 생체 기반 여권 |
