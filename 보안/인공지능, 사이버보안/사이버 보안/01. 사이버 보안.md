
1. **사이버 보안**
   👉 컴퓨터, 네트워크, 데이터를 공격으로부터 보호하는 모든 활동


보안 목표
* 가용성 : 필요할 때 언제든 시스템을 사용할 수 있다.
* 메세지 인증
* 무결성(ex. 부인 방지) : 데이터가 변조되지 않고 원래 상태를 그대로 유지한다
* 기밀성 : 허가 된 사람만 정보를 볼 수 있다

사이버 보안
- 정보보호 : 정보를 지킨다
- 물리보안 : 물리적인 방법으로 지킨다 (ex. 출입통제, CCTV)
- 융합보안 : 정보보안 + 물리보안으로 강력하게 보호하는 것을 의미

---

2. **프라이버시**
   👉 사생활 보호 + 개인 정보 보호
---

3. **인가 (Authorization)**
   👉 “이 사람이 이걸 해도 되는가?”를 결정하는 권한 부여

   목록 기반 접근제어(list-based access control) : IP를 직접 지정해서 허용/거부 하는 방식
   역할 기반 접근제어(RBAC) : 사용자 -> '역할' / 역할 기준으로 접근 권한을 설정하는 방식 ex. admin, employ
   정책 기반 접근제어(PBAC) : 조건(시간, 위치, 디바이스 등)에 따라 정책으로 접근을 결정하는 방식
         Zero Trust 모델에서 많이 사용

---

4. **인증 (Authentication)**
   👉 “이 사람이 누구인가?”를 확인하는 과정

   ID/Password 확인, 인증부호, 암호, 디지털 서명
---

5. **트랩도어 (Trapdoor)**
   👉 정상적인 인증 없이 시스템에 몰래 들어갈 수 있는 숨겨진 경로

1. 개발/테스트 용도

* 로그인 없이 관리자 기능 접근
* 디버깅 빠르게 하기 위해

2. 유지보수/긴급 접근
* 시스템 문제 생겼을 때 빠르게 접속하기 위해

---

6. **사이버 공격**
   👉 시스템이나 데이터를 해치기 위해 의도적으로 시도하는 모든 행위

렌섬웨어: 파일을 암호화해서 못쓰게 만든 뒤 금전을 요구
스파이웨어: 사용자 몰래 정보를 훔쳐가는 악성코드
바이러스: 정상 파일에 붙어서 실행될 때 전파되는 악성코드
웜: 자기 혼자 네트워크를 통해 자동으로 퍼지는 악성코드

피싱: 가짜 사이트 / 메일로 사용자를 속여 개인정보를 빼내는 공격
파밍: 사용자가 올바른 주소를 입력해도 가짜 사이트를 보내는 공격 -> DNS 변조, 라우터 해킹등을 통해 접속을 가로채는 공격
중간자 공격: 통신 중간에서 몰래 가로채고 내용을 훔치거나 변경하는 공격 (공용 wifi에서 로그인 정보 탈취 / HTTPS 없는 사이트에서 데이터 변조)
서비스 거부(DOS attack): 시스템에 과도한 요청을 보내 서비스를 마비시키는 공격
DDoS attack:시스템에 과도한 요청을 보내 서비스를 마비시키는 공격

* DOS vs DDOS

: DOS는 한 대가 공격, DDOS는 여러 대가 분산 공격   

SQL injection: 웹입력값을 조작해서 DB 쿼리를 바꾸는 공격
Zero-day attack: 아직 패치되지 않은 보안 취약점을 이용하는 공격
 
* 핵티비즘 : 정치적 사회적 목적을 위해 해킹을 사용하는 행위

---

7. **사이버 위협 인텔리전스 (CTI)**
   👉 해커의 공격 정보와 패턴을 수집·분석해서 미리 대비하는 것

OSINT : 인터넷 등 공개된 정보를 수집하는 방법
SOCIMINT : sns에서 공개된 정보를 수진, 분석해 우협 정보를 얻는 활동
HUMINT : 사람들을 통해 직접 얻는 정보

---

8. **다크웹**
   👉 일반 검색으로 접근할 수 없는, 익명성이 높은 인터넷 영역

   토어 TOR : 트래픽을 여러 노드를 거쳐 암호화하며 익명성을 제공하는 네트워크
   I2P : 완전히 내부 네트워크 형태로 구성된 익면 P2P 통신망 (인터넷 안에 또 다른 인터넷)

---

9. **스파이 앱 (Spy App)**
   👉 사용자의 정보나 행동을 몰래 수집하는 악성 프로그램

---

10. **확장형 위협 탐지 및 대응 (XDR)**
    👉 여러 보안 시스템을 통합해서 공격을 탐지하고 대응하는 기술
