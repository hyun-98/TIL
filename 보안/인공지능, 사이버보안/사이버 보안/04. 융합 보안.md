# 📘 Converged Security & Emerging Security Concepts

---

# 1. 🔐 융합 보안 (Converged Security)

👉 정보보안 + 물리보안 + 산업보안을 통합해서 하나의 체계로 관리하는 보안

## 🔍 구성

- **정보 보안 (Information Security)**
  - 네트워크, 시스템, 데이터 보호

- **물리 보안 (Physical Security)**
  - 출입 통제, CCTV, 시설 보호

- **산업 보안 (Industrial Security)**
  - 기술 유출 방지, 산업 스파이 대응

## 🧠 특징
- 개별 보안이 아니라 “전체 환경 통합 보호”
- 기업/국가 핵심 인프라에서 중요

## 🎯 핵심
👉 “모든 보안을 하나로 묶는 통합 보안 모델”

---

# 2. 🧠 인물 합성 기술 탐지 (Deepfake Detection)

👉 AI로 만든 가짜 얼굴/음성/영상(딥페이크)을 탐지하는 기술

## 🔍 딥페이크란?
- AI로 사람 얼굴/음성을 합성하는 기술
- 실제처럼 보이지만 가짜 콘텐츠

## 🔥 탐지 방법

- 얼굴 움직임 분석 (눈 깜빡임, 표정 비정상)
- 음성 주파수 분석
- 픽셀 노이즈 분석
- AI 기반 탐지 모델

## ⚠️ 위험성
- 정치적 가짜 뉴스
- 금융 사기
- 신원 도용

## 🎯 핵심
👉 “AI로 만든 가짜 사람을 AI로 잡는 기술”

---

# 3. 🔗 공급망 보안 (Supply Chain Security)

👉 제품이나 소프트웨어가 만들어지고 전달되는 전체 과정에서 발생하는 보안 위협을 방어하는 것

## 🔍 범위
- 하드웨어 제조
- 소프트웨어 개발
- 업데이트 배포
- 클라우드 서비스

## 💣 공격 예시
- 업데이트 파일에 악성코드 삽입
- 개발 도구 해킹
- 라이브러리 변조

## 🧠 특징
- 직접 시스템 공격이 아니라 “경로 공격”
- 탐지가 매우 어려움

## 🎯 핵심
👉 “제품이 만들어지는 과정 자체를 공격하는 보안 위협”

---

# 4. 🤖 사이버-물리 시스템 (CPS, Cyber-Physical System)

👉 컴퓨터 시스템이 현실 세계의 물리 시스템과 연결되어 제어하는 구조

## 🔍 구성

- Cyber (컴퓨터/네트워크)
- Physical (현실 장비/기계)
- Sensor (데이터 수집)
- Actuator (동작 수행)

## 🧠 예시

- 스마트 팩토리
- 자율주행 자동차
- 스마트 그리드
- 의료 장비 시스템

## 💥 위험성
- 해킹 시 실제 물리 피해 발생
- 공장 멈춤 / 차량 사고 가능

## 🎯 핵심
👉 “디지털 공격이 현실 세계를 직접 공격하는 시스템”
