# 1. **정보 보호**

→ 정보의 기밀성·무결성·가용성을 유지해 안전하게 지키는 것

* 기밀성: 허가 된 사람만 정보를 볼 수 있게 하는것
* 무결성: 데이터가 변하지 않음
* 가용성: 항상 시스템에 접속 가능
* 부인방지: 특정 행위를 했다는 사실을 부인하지 못하게 하는 것
* 인증: 누구인지 확인 가능

---

# 2. **가상 사설 통신망 (VPN)**

→ 인터넷 위에 암호화된 전용 통신 터널을 만들어 안전하게 연결하는 기술

* IPSec VPN: IP 계층에서 데이터를 암호화하는 VPN
* SSL VPN: 웹으로 암호화 된 VPN

---

# 4. **방화벽 (Firewall, FW)**

→ 네트워크 트래픽을 필터링해 허용/차단을 결정하는 보안 장치

* 인증 기능
* 패킷에 대해 보안 정책을 기반으로 패킷 필터링을 수행하는 접근 통제 기능
* 목적지 IP주소가 어떤 인터페이스로 이동해야 할지 결정하는 경로 설정 기능
* 관리자 접근
* 정책 설정 변경 및 패킷의 허용 및 차단과 관련한 이력 저장 (로그)
* 내부 사설 IP를 공인 IP로 변환하는 NAT 기능

---

# 6. **침입 탐지 시스템 (IDS) -> IPS**

→ 비정상적인 공격이나 침입 시도를 탐지해 알리는 시스템

---

# 7. **엔드포인트 탐지 및 대응 (EDR)**

→ PC·서버 등 단말에서 위협을 탐지하고 대응까지 수행하는 보안 솔루션

---

# 8. **제로데이 공격**

→ 보안 취약점이 공개되기 전에 이를 악용하는 공격

---

# 9. **DDoS 공격**

→ 여러 대의 시스템으로 동시에 요청을 보내 서버를 마비시키는 공격

---

# 11. **서비스형 랜섬웨어 (RaaS)**

→ 랜섬웨어를 서비스처럼 제공해 누구나 공격에 활용할 수 있게 한 모델

---

# 12. **제로 트러스트 (Zero Trust)**

→ “아무도 믿지 않는다”는 전제로 모든 접근을 계속 검증하는 보안 모델

---

# 13. **컴퓨터 포렌식스**

→ 디지털 증거를 수집·분석해 범죄나 사고 원인을 밝혀내는 기술

---

# 14. **피싱 (Phishing)**

→ 가짜 사이트나 메시지로 사용자를 속여 개인정보를 탈취하는 공격

---

# 15. **양자 암호**

→ 양자역학 원리를 이용해 해킹이 거의 불가능한 암호 기술

* 양자암호키분배 QKD

---

# 16. **정보보호 최고 책임자 (CISO)**

→ 조직의 정보보호 전략과 보안을 총괄하는 책임자

---

# 17. **개인정보 보호책임자 (CPO)**

→ 개인정보 보호 정책과 관리·감독을 담당하는 책임자

---

# 18. **정보보호 관리체계 인증 (ISMS)**

→ 기업이 일정 수준 이상의 보안 관리체계를 갖췄음을 인증하는 제도
