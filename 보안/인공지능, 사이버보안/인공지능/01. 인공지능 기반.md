2. 기반 모델 :

대규모 언어 모델
전이 학습 : 인공지능 분야에서 이미 학습된 모델의 지식을 새로운 태스크에 적용하는 방법

[chatgpt]
여러 가지 일을 할 수 있는 AI
어떤 문제를 줘도 잘푸는 모델
ex. chatgpt, gemini
-> 이 모델 위에 다른 모델(서비스)를 만들 수 있기 때문에 기반 모델이라고 부른다


3. 확산 모델 : 기계 학습에서 데이터가 점차적으로 노이즈를 추가하는 '확산 과정'과 '이를 역으로 따라가며 노이즈를 제거해 원래 데이터를 복원하는 역확산 과정을 학습함으로써, 새오룽ㄴ 데이터를 생성하는 생성 모델

[chatgpt]
망가진 데이터를 점점 복구해서 새로운 결과를 만드는 AI

4. 멀티모달 인공지능 : 여러 가지 종류의 정보를 동시에 이해하는 AI

5. 인간 피드백 기반 강화 학습 (RLHF)

AI 답변을 사람이 평가
ex. ChatGPT가 답변 2개 생성 -> 인간이 더 좋은 답 선택 -> AI가 그 방향으로 학습

6. 자기지도형 기계 학습 (Self-supervised Learning)

정답 없이 데이터 자체로 배우는 학습

7. 검색 증강 생성 (RAG) !

AI가 검색해서 정보를 찾아 답하는 방식

8. 소수 예시 기반 학습 (Few-shot) !

몇개의 예시만 보고 배우는 것

9. 무 예시 기반 학습 (Zero-shot) !

예시 없이 바로 문제 해결

10. 미세 조정 (Fine-tuning)

이미 만든 AI를 특정 용도로 더 학습
ex. 일반 AI -> 의료 데이터로 추가 학습 -> 의료 AI 완성

11. 모델 경량화

AI를 더 가볍고 빠르게 만드는 것
ex. 큰 AI -> 스마트폰에서도 실행 가능하게 축소

12. 연합 학습 (Federated Learning) !

데이터를 모으지 않고 각 기기에서 학습

13. 합성 데이터

AI가 만든 가짜 데이터
ex. 사람 얼굴 사진 부족 -> AI가 가짜 얼굴 생성

14. 대조 학습 (Contrastive Learning)

비교하면서 배우는 AI
ex. 강아지 vs 고양이 비교 -> 특징 학습

15. 언어, 이미지 대조 사전 학습

글과 이미지를 함께 학습하는 방식
ex. '고양이' 단어 + 고양이 이미즈 -> 연결 학습

16. 메타 학습 (Meta Learning)

학습하는 방법 자체를 배우는 AI
ex. 공부하는 법을 배우는 것
