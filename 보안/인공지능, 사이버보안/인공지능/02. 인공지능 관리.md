1. 데이터옵스 (DataOps)

데이터를 자동으로 모으고, 정리하고, 시스템으로 바로 쓸 수 있게 만드는 것
ex. 쇼핑몰 -> 판매 데이터 자동 수집 / 인기 상품 바로 분석

2. ML옵스 (MLOps)

AI를 만들고 운영
ex. AI 개발 -> 정상 작동되는 확인 및 개선

3. 휴먼인더루프 (Human-in-the-Loop)

AI가 다 하지 않고 사람이 중간에 검토
ex. 번역 AI -> 사람이 검토 / 자율주행 -> 위험하면 사람이 운전

4. 신뢰 가능 인공지능 (Trustworthy AI)

믿고 사용할 수 있는 AI / 틀리지 않고, 공정하고, 안전한 AI

5. 인공지능 윤리 (AI Ethics)

AI를 올바르게 쓰기 위한 규칙
ex. 얼굴 인식 -> 사생활 침해 문제 / AI 그림 저작권 문제

6. 데이터 편향 (Data Bias)

데이터가 한 쪽으로 치우친 문제 (공정하지 않음)
데이터 편향의 문제
ex. 남자 데이터만 학습한 채용 AI -> 여자 지원자를 불리하게 평가

7. 허위 생성 (Hallucinatuin)

AI가 없는 사실을 만들어냄
ex. 존재하지 않은 뉴스나 논문을 말함 / 틀린 정보를 확신 있게 설명

8. 설명 가능 인공지능 (XAI)

AI 가 왜 그렇게 판단했는지 설명해주는 기술
-> 결과 + 이유도 알려줌

9. 지속 가능 인공지능 (Sustainalble AI)

환경을 생각하면서 AI를 사용
ex. AI 학습 시 전력 절약 / 효율적인 모델 사용
